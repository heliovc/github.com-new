The code (rename.py)
from pathlib import Path

folder = Path("photos")
files = sorted(folder.glob("*.JPG"))

for i, old in enumerate(files, start=1):
    new = old.with_name(f"trip-{i:03d}{old.suffix.lower()}")
    print(old.name, "→", new.name)
    old.rename(new)

Safer version (sort by date + never overwrite)
from pathlib import Path

folder = Path("photos")
files = sorted(folder.glob("*.JPG"), key=lambda p: p.stat().st_mtime)

for i, old in enumerate(files, start=1):
    new = old.with_name(f"trip-{i:03d}{old.suffix.lower()}")
    if new.exists():
        print("skip:", new.name, "already exists")
        continue
    old.rename(new)

Tested on Python 3. On Windows, *.JPG also matches .jpg (file names are not case sensitive).
